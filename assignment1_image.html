2. Dataset, Dataloader, And Augmentation Preparation

The dataset pipeline in training/dataset.py supports loading from both folders and .zip files, then applies stratified splitting to preserve class distribution. 

variant = "original" | "augmentation" | "combined"
records = collect_records(data_root, variant)
splits = split_records(records, val_size=0.1, test_size=0.1, seed=42)

The dataloader uses configurable batch size and workers from YAML config files. Augmentations are implemented in training/transforms.py:

  • RandomHorizontalFlip (default 0.5)
  • RandomRotation (default 15 degrees)
  • ColorJitter (brightness/contrast/saturation/hue)
  • RandomResizedCrop (scale 0.8-1.0, ratio 0.9-1.1)
  • ImageNet normalization

3. Model Building, Training, Evaluation, And Comparison

Three backbones are compared: ResNet50, EfficientNet-B6, and ViT-B16. Across 2 data modes (original/augmentation) and 3 fine-tuning strategies (frozen, linear probe, finetune all), the pipeline runs 15 experiments.

The training engine uses CrossEntropyLoss (label smoothing), AdamW, CosineAnnealingLR, early stopping, and TensorBoard logging per batch/epoch.
