2. Dataset, Dataloader, And Augmentation Pipeline

The pipeline in training/dataset.py supports loading data from both directories and .zip archives, then applies stratified splitting to preserve class balance. 

variant = "original" | "augmentation" | "combined"
records = collect_records(data_root, variant)
splits = split_records(records, val_size=0.1, test_size=0.1, seed=42)

Dataloader settings come from YAML config, while augmentations in training/transforms.py include:

  • RandomHorizontalFlip (default 0.5)
  • RandomRotation (default 15 degrees)
  • ColorJitter (brightness/contrast/saturation/hue)
  • RandomResizedCrop (scale 0.8-1.0, ratio 0.9-1.1)
  • ImageNet normalization

3. Model Building, Training, Evaluation, And Comparison

Three backbones are benchmarked: ResNet50, EfficientNet-B6, and ViT-B16. Across 2 data modes and 3 fine-tuning strategies, the pipeline executes 15 runs.

Training uses CrossEntropyLoss with label smoothing, AdamW, CosineAnnealingLR, early stopping, and TensorBoard logging.

5. Extension Report: Interpretability (Grad-CAM & Attention Rollout)

The project includes visual explanation tools from utils/visualization.py: Grad-CAM for CNN models and Attention Rollout for ViT.

  • Grad-CAM highlights spatial regions that drive CNN predictions.
  • Attention Rollout visualizes important token regions in transformer inference.
  • These visuals improve model trust and support qualitative error analysis.
